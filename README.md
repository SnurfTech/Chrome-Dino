# SnurfTech's Chrome Dino
A bundled version of the classic no-internet Chrome Dino game.

---

Go to releases to get a prebuilt version

Clone this repository, run ```npm install```, and run one of these commands to build the game yourself:

|```npm run build```|```npm run build:bun```|```npm run build:min```|```npm run build:fresh```|
|---|---|---|---|
|Downloads the Chromium project repository and builds the bundled game normally, but if the Chromium repository is already downloaded, it uses that|The same as the first, but ran via Bun|The same as the first, but builds the game minified|The same as the first, but redownloads the Chromium repository no matter what|
